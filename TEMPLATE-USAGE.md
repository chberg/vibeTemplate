# Vibe Factory Template Usage

1. **Source of Truth**: This directory is the source-of-truth template. Do not edit it from inside generated projects.
2. **To Use**: Run `.\vibe-factory-starter\vibe-init.ps1 <project-name> <parent-dir>` (or `./vibe-factory-starter/vibe-init.sh`) from this directory.
3. **To Improve**: Edit files here, commit, bump the tag, then re-run `vibe-init` for new projects.
4. **No Auto-Update**: Generated projects do NOT auto-update when this template changes (this is intentional to prevent breaking existing projects).
